# Scratchpad & Editor Tabs Policy

1. **No Scratchpads in Open Tabs**:
   - Do not create scratchpad files or internal markdown notes that appear in the user's top open file tab bar.
   - When creating internal temporary files or artifacts, always mark them with UserFacing: false.
   - Never generate visible scratchpad files in the workspace or brain directory that pollute the editor tab bar.
   - If any automated tool or subagent generates temporary scratchpads, clean them up immediately so they do not open in the user's editor.
